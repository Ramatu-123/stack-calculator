## Description
A Python program that reads mathematical expressions from `input.txt`, evaluates each one using a stack-based approach, and writes the results to `output.txt`.

It supports the operators `+`, `-`, `*`, `/`, parentheses, and operator precedence (`*` and `/` are done before `+` and `-`).

## Files in this project
| File | Purpose |
|------|---------|
| `stack_calculator.py` | The Python source code |
| `input.txt` | Sample input file used for testing |
| `output.txt` | Output generated by the program |
| `README.md` | This documentation |

## How to run
1. Install Python 3 on your computer.
2. Put `stack_calculator.py` and `input.txt` in the same folder.
3. Open a terminal or command prompt in that folder.
4. Run: `python stack_calculator.py`
5. Open `output.txt` to see the results.

If `input.txt` is missing, the program creates a sample one automatically.

## Input file format
- One expression per line.
- Expressions are separated by a line containing only dashes (`-----`).

Example `input.txt`:
```
3 + 5 * 2
-----
(8 / 4) + 7 * 2
-----
10 - (2 + 3) * 4
```

## Output file format
- One result per line, separated by the same `-----` line.
- Invalid expressions show an error message instead of crashing the program.

Example `output.txt`:
```
13
-----
16
-----
-10
```

## How the program works
1. A `Stack` class provides `push`, `pop`, `peek` and `is_empty`.
2. The `evaluate` function uses two stacks: one for numbers and one for operators.
3. Operators with higher precedence are applied first, and parentheses force the inner part to be calculated first.
4. The program reads every expression from `input.txt`, evaluates it, and writes the results to `output.txt`.

## Assumptions and limitations
- Negative numbers such as `-5 + 3` are not supported.
- Only numbers and the characters `+ - * / ( )` are allowed.
- The assignment's sample output shows `17` for `(8 / 4) + 7 * 2`, but the correct answer is `16` (8 / 4 = 2, 7 * 2 = 14, 2 + 14 = 16). This program outputs `16`.
- Invalid input (division by zero, mismatched parentheses, invalid characters) produces an error message in `output.txt`.
